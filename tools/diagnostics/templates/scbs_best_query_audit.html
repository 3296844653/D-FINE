统计口径、文件来源与注意事项
  • 高 IoU 指 best-IoU query 与 GT 的 IoU≥0.75。另一高分正确 query 必须是不同 query，最高分类别为 GT，分数≥0.5，进入原 top-k，并与该 GT 的 IoU≥0.5。
  • 类别错误优先归 C/D；A/B 要求 best query 的最高分类正确。E 为类别正确且高分，F 为 best IoU＜0.75。
  • D-FINE 的 top-k 按 query×类别预测对选择。同一个 query 可能同时输出 read 和 write；“query 最高类别”与“某个预测对的类别”不完全相同。
  • A/C 只代表存在替代正确候选；B/D 是候选证据，不是已经确认的评分或分类原因。这些抽样不能用于估算总体准确率，也不能直接定位网络层。
  • GT 标签沿用原标注，尚未经过这次人工核查。网页使用原图字节和导出的精确框／分数，没有重新推理或增强图片。
  • 局部图中的 B/L/P 编号是显示标记，框坐标未改变。点击完整原图查看整个场景；局部显示筛选不影响实际预测结果。
